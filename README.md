#🧑‍💼 Employee Attendance & Leave Management System

A full-stack web application to manage employee attendance, leave requests, and role-based access for Admin and Employee users.

🚀 Tech Stack
Frontend: React, TypeScript, Tailwind CSS
Backend: Node.js, TypeScript, Express
Database: PostgreSQL
Auth: JWT, bcrypt

👥 User Roles

Admin
Manage employees
Monitor attendance
Approve/reject leave requests
View analytics dashboard

Employee
Punch in / punch out
Apply for leave or permission
View attendance & leave history

🔐 Key Features

Secure login with JWT
Role-based access control
Attendance tracking
Leave & permission management
Dashboard analytics
Responsive UI

📂 Project Structure

backend/    → APIs, authentication, database logic  
frontend/   → UI and dashboards  
database/   → PostgreSQL schema

⚙️ Setup

# Backend
cd backend
npm install
npm run dev

# Frontend
cd frontend
npm install
npm run dev
